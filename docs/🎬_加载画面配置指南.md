## 🎯 配置代码说明

### loading_screen.gd 关键代码

```gdscript
# 图片加载路径
var image_path = "res://assets/loading_screen.png"

# 自动进入游戏时间（秒）
var transition_time: float = 3.0

# 自动进入游戏
if elapsed_time >= transition_time:
    _transition_to_game()

# 点击跳过
func _input(event):
    if event is InputEventMouseButton or event is InputEventKey:
        _transition_to_game()
```
