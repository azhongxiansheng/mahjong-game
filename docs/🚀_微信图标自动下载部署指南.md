## 🎯 完整功能说明

### 📥 Python 脚本下载工具

#### 基本用法

```bash
# 默认下载：40x40 SVG 格式
python download_wechat_icon.py

# 下载其他尺寸
python download_wechat_icon.py --size 64

# 下载 PNG 格式
python download_wechat_icon.py --format png

# 同时指定多个参数
python download_wechat_icon.py --size 48 --format png

# 强制刷新（忽略缓存）
python download_wechat_icon.py --force

# 清理缓存
python download_wechat_icon.py --clear-cache

# 查看帮助
python download_wechat_icon.py --help
```

#### 高级用法（手动调用）

```gdscript
# 在任何脚本中手动下载
var icon_manager = WeChatIconManager.new()
add_child(icon_manager)

# 快速模式（默认 40x40 SVG）
await icon_manager.auto_download_icon(func(success, msg):
    if success:
        print("✅ 图标已更新: ", msg)
    else:
        print("⚠ 图标更新失败: ", msg)
)

# 指定规格下载
await icon_manager.download_icon(64, "png", false, func(success, msg):
    print("下载完成:", success, msg)
)

# 获取图标配置
var specs = icon_manager.get_icon_specs()
print("支持的尺寸:", specs.sizes)
print("支持的格式:", specs.formats)

# 获取推荐配置
var recommended = icon_manager.get_recommended_icon()
print("推荐尺寸:", recommended.size)
print("推荐格式:", recommended.format)

# 清理缓存
icon_manager.clear_icon_cache()
```

#### 脚本类说明

##### WeChatIconDownloader

底层下载器，负责文件下载和图标生成：

```gdscript
# 创建实例
var downloader = WeChatIconDownloader.new()
add_child(downloader)

# 下载图标
var success = await downloader.download_icon(
    size: int = 40,           # 图标尺寸
    format: String = "svg",   # 图标格式
    force_refresh: bool = false # 强制刷新
)

# 获取可用配置
var icons = downloader.get_available_icons()

# 清理缓存
downloader.clear_cache()

# 信号
downloader.download_started.connect(func(): print("开始"))
downloader.download_progress.connect(func(p, m): print(p, m))
downloader.download_completed.connect(func(s, m): print(s, m))
```

##### WeChatIconManager

高级接口，简化图标管理：

```gdscript
# 创建实例
var manager = WeChatIconManager.new()
add_child(manager)

# 快速下载
await manager.auto_download_icon(callback)

# 指定参数下载
await manager.download_icon(size, format, force_refresh, callback)

# 获取信息
manager.get_icon_specs()      # 获取规格信息
manager.get_recommended_icon() # 获取推荐配置

# 缓存管理
manager.clear_icon_cache()
```

## 🐛 故障排查

### 问题 1：GitHub 下载失败

**症状**：
```
⚠ GitHub 下载失败: [Errno 11001] getaddrinfo failed
```

**原因**：网络连接问题或 GitHub 不可访问

**解决方案**：
```bash
# 1. 检查网络连接
ping github.com

# 2. 使用本地生成（自动发生）
# 脚本会自动生成官方风格的本地图标

# 3. 重新尝试
python download_wechat_icon.py --force
```

### 问题 2：PNG 生成失败

**症状**：
```
⚠ PIL 库未安装，无法生成 PNG 图标
```

**原因**：没有安装 Pillow 库

**解决方案**：
```bash
# 安装 Pillow
pip install Pillow

# 重新下载
python download_wechat_icon.py --format png
```

### 问题 3：权限被拒绝

**症状**：
```
❌ 无法写入目标文件: D:\MahjongGame\godot\assets\...
```

**原因**：文件权限问题或文件被占用

**解决方案**：
```bash
# 1. 关闭 Godot 编辑器
# 2. 以管理员身份运行命令
# 3. 清理缓存后重试
python download_wechat_icon.py --clear-cache
python download_wechat_icon.py --force
```

### 问题 4：Godot 中图标不显示

**症状**：加载画面中微信登录按钮没有显示图标

**原因**：
- 图标文件路径不正确
- 需要刷新 Godot 资源缓存

**解决方案**：

```
1. 在 Godot 编辑器中
2. 菜单 → 文件 → 刷新
3. 或按 Ctrl + Shift + R
4. 重新打开加载画面场景
```

## 💬 常见问题 (FAQ)

### Q: 图标会不会过期？
**A**: 不会。官方图标设计稳定，即使微信更新，我们也会及时跟进。

### Q: 可以修改图标吗？
**A**: 不建议修改。为了符合微信品牌规范，请使用官方原始图标。

### Q: 支持其他社交平台吗？
**A**: 当前仅支持微信。未来可扩展到其他平台。

### Q: 如何离线使用？
**A**: 第一次下载后会缓存，后续可离线使用缓存的图标。

### Q: 可以在移动平台使用吗？
**A**: 是的，SVG 和 PNG 都支持所有平台。
