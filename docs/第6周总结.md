## 核心算法讲解

### 听牌检测算法

```
1. 获取手中已有的花色
2. 只检查相关花色（避免检查完全没有的花色）
3. 对每张可能的牌：
   - 临时添加到手牌
   - 调用 WinChecker 检测是否能胡
   - 记录能胡的牌
4. 返回听牌列表和统计信息
```

**时间复杂度：** O(n × m)，其中 n = 花色数量，m = 每花色的牌数

### AI 出牌决策

**简单策略流程：**
```
EAS Y → 直接随机
NORMAL → 找老头牌(1,9) → 如果没有则随机
HARD → 检测听牌 → 如果听牌则谨慎 → 否则争取听牌
EXPERT → 评估所有出牌 → 计算每张出牌后的听牌价值 → 选最优
```
