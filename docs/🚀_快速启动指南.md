## 🎮 功能介绍

### 1️⃣ 核心游戏逻辑
- **卡牌系统**: 万筒条字四种花色，1-9 数字，共 136 张牌
- **手牌管理**: 完整的入手、出牌、听牌逻辑
- **胡牌规则**: 
  - 标准胡牌 (平胡)
  - 全刻胡牌 (刻子胡)
  - 清一色胡牌 (同花)
  - 七对胡牌
  - 十三幺胡牌
  - 等等...
- **听牌检查**: 快速识别可以胡的所有牌型

### 2️⃣ 用户界面
- **卡牌显示**: 美观的卡牌渲染
- **手牌 UI**: 拖拽选择，自动排序
- **动画效果**: 摸牌、出牌、胡牌动画
- **大厅界面**: 房间创建、玩家配对
- **游戏界面**: 实时游戏状态显示

### 3️⃣ AI 对手
- **三个难度等级**:
  - 🟢 简单: 随机出牌
  - 🟡 中等: 根据听牌概率出牌
  - 🔴 困难: 智能分析和预测

### 4️⃣ 网络多人
- **WebSocket 通信**: 低延迟双向通信
- **房间系统**: 创建、加入、离开房间
- **玩家配对**: 自动匹配配对
- **实时同步**: 0.5秒同步间隔
- **冲突解决**: 自动版本比较和合并

### 5️⃣ 性能优化
- **缓存系统**: 10-100倍性能提升
- **异步处理**: 非阻塞操作
- **对象池**: 内存管理优化
- **智能清理**: 自动过期数据清理

## 🎮 游戏玩法

### 基础流程

```
1. 连接服务器
   ↓
2. 进入大厅
   ↓
3. 创建房间或快速配对
   ↓
4. 等待其他玩家加入
   ↓
5. 开始游戏
   ├─ 摸牌
   ├─ 打出一张牌
   ├─ 等待其他玩家
   ├─ 重复直到有人胡牌
   ↓
6. 计算得分
   ↓
7. 返回大厅或再来一局
```

| 键 | 功能 |

| `O` | 测试对手手牌 |

## 📱 主要 API 速查

### 卡牌操作

```gdscript
# 创建卡牌
var card = CardData.new(CardData.Suit.WAN, 5)

# 创建手牌
var hand = CardHand.new()
hand.add_card(card)

# 获取卡牌数量
var count = hand.get_card_count()
```

### 胡牌检查

```gdscript
# 检查是否能胡
var hand = CardHand.new()
# ... 添加卡牌 ...
var result = WinChecker.check_win(hand)
if result.can_win:
    print("可以胡牌！")
```

### 听牌检查

```gdscript
# 检查可以听哪些牌
var hand = CardHand.new()
# ... 添加13张卡牌 ...
var ting_cards = WinChecker.check_can_hear(hand)
print("可以听: %d 种牌" % ting_cards.size())
```

### 网络连接

```gdscript
# 创建网络客户端
var client = NetworkClient.new()

# 连接到服务器
client.connect_to_server()

# 创建房间
client.create_room("MyRoom", 4)

# 加入房间
client.join_room(room_id)
```

### 游戏同步

```gdscript
# 创建同步器
var sync = GameSynchronizer.new()

# 本地出牌
sync.local_play_card("player_1", card_data)

# 本地摸牌
sync.local_draw_card("player_1")

# 声明胜利
sync.local_declare_win("player_1", win_data)
```

## 🐛 常见问题

### Q: 如何编译项目？
**A**: 在 Godot 编辑器中，点击 **File → Export Project**，选择目标平台即可。

### Q: 网络功能如何工作？
**A**: 
1. 需要运行 Go 后端服务器
2. 服务器监听 WebSocket 连接
3. 客户端通过 WebSocket 连接到服务器
4. 消息采用 JSON 格式

### Q: 如何调试网络问题？
**A**: 
```gdscript
# 启用网络调试
var debugger = NetworkDebugger.new()
debugger.enable_logging(true)
debugger.print_network_report()
debugger.print_debug_info()
```

### Q: 性能不足怎么办？
**A**: 
1. 启用缓存系统: `WinChecker.init_cache()`
2. 使用异步检查: `AsyncTingChecker`
3. 调整同步间隔
4. 分析瓶颈代码

### Q: 如何添加新的特殊牌型？
**A**: 编辑 `SpecialWinChecker` 类：
```gdscript
static func check_special_win(hand: CardHand) -> Dictionary:
    # 添加新的胡牌检查逻辑
    pass
```
