## 📚 核心代码实现

### 1️⃣ CardData 类（卡牌数据）

```gdscript
class_name CardData

enum Suit { WAN = 0, TONG = 1, TIAO = 2, ZI = 3 }

var suit: Suit
var number: int
var id: int

func _init(p_suit: Suit, p_number: int) -> void:
    suit = p_suit
    number = p_number
    id = int(suit) * 10 + p_number

func get_card_name() -> String:
    var suit_names = ["万", "筒", "条", "字"]
    return suit_names[suit] + str(number)

func can_pair_with(other: CardData) -> bool:
    return suit == other.suit and number == other.number

func get_rank() -> String:
    if number == 1:
        return "幺"
    elif number <= 5:
        return "小"
    else:
        return "大"
```

**学习点**：
- ✅ 枚举定义和使用
- ✅ 构造函数（_init）
- ✅ 条件判断（if/elif/else）
- ✅ 返回值类型指定

### 2️⃣ CardHand 类（手牌管理）

```gdscript
class_name CardHand

var cards: Array = []

func add_card(card: CardData) -> void:
    cards.append(card)

func find_card(suit: int, number: int) -> CardData:
    for card in cards:
        if card.suit == suit and card.number == number:
            return card
    return null

func get_cards_by_suit(suit: int) -> Array:
    var result: Array = []
    for card in cards:
        if card.suit == suit:
            result.append(card)
    return result

func sort_cards() -> void:
    cards.sort_custom(func(a: CardData, b: CardData) -> bool:
        if a.suit != b.suit:
            return a.suit < b.suit
        return a.number < b.number
    )
```

**学习点**：
- ✅ 数组操作（append, remove_at）
- ✅ for 循环遍历
- ✅ Lambda 函数和自定义排序
- ✅ 条件判断嵌套
