## 🔧 如果遇到问题

### 问题：还是黑屏？
```
解决方案：
1. Ctrl+S 保存所有文件
2. 关闭 Godot
3. 删除 .godot 文件夹
4. 重新打开
```

### 问题：错误信息还在？
```
解决方案：
1. File → Reload Current Scene (Ctrl+Shift+F5)
2. 等待重新加载
3. 按 F5 重新运行
```

### 问题：卡牌显示混乱？
```
解决方案：
1. 检查 hand_display.gd 的 spacing 计算
2. 确保是动态计算（`max(10, ...)`）
```
