# 🔧 Godot 加载错误快速修复指南

## 问题症状

```
[加载出错] res://scenes/game_ui.tscn
"由于缺少依赖项，加载出错。加载次数："
应采取哪项操作？
☐ 仍然打开  ☑ 关闭  [修复依赖项]
```

## 🚀 快速修复（3步）

### 步骤 1: 关闭错误对话框
```
点击 [修复依赖项] 或 [关闭]
```

### 步骤 2: 清除 Godot 缓存
```
方案 A（最快）:
1. 关闭 Godot 完全退出
2. 打开文件资源管理器
3. 导航到 D:\MahjongGame\godot
4. 删除 .godot 文件夹（隐藏文件，可能需要显示隐藏文件）
5. 重新打开 Godot

方案 B（使用菜单）:
1. File → Reload Current Scene（Ctrl+Shift+F5）
2. 等待重新加载
3. 如果还是不行，重启 Godot
```

### 步骤 3: 重新运行
```
按 F5 启动游戏
```

---

## ❓ 为什么会出现这个错误？

1. **缓存问题** - Godot 的 UID 缓存过时
2. **路径变更** - 我们改变了场景结构
3. **脚本编译** - 新添加的动画代码需要重新编译

这是**完全正常的**，不影响代码本身。

---

## 🆘 如果还是不行

### 问题：重启后仍然有同样错误

**解决方案**：
```
1. 在 Godot 编辑器中打开 game_ui.tscn
2. Inspector 右上角点击刷新按钮
3. File → Save
4. 关闭并重新打开 Godot
```

### 问题：看不到 .godot 文件夹

**解决方案**：
```
在 Windows 中显示隐藏文件：
1. 打开 D:\MahjongGame\godot
2. View → Show hidden files
3. 找到 .godot 文件夹删除
```

### 问题：仍然无法加载

**解决方案**（终极重置）：
```
1. 关闭 Godot
2. 删除以下文件夹：
   - .godot
   - .vscode
   - .vs
3. 删除所有 *.uid 文件
4. 重新打开 Godot
5. 按 F5 测试
```

## 📝 技术背景

当您调整了场景结构（比如改为 4 人布局）时，Godot 的缓存可能指向旧的 UID。这就是为什么需要清除缓存让 Godot 重新扫描所有资源。
