## ❓ 常见问题速答

| 问题 | 答案 |
|------|------|
| **图标不显示？** | 检查路径是否正确，查看控制台错误 |
| **如何替换图标？** | 下载新图标放到 assets/ 目录，更新引用路径 |
| **能修改图标吗？** | ❌ 不能，必须使用官方原始图标 |
| **支持其他格式？** | ✅ 可以，官方提供 PNG 和 SVG 格式 |
| **图标太小？** | 下载更大尺寸（64×64 或 128×128） |
