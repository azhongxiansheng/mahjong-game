## 🎯 第3-4周: GDScript编程语言

### 5个核心概念

1. **变量** (Variable)
   ```gdscript
   var health = 100
   var name = "Player"
   var position = Vector2(10, 20)
   ```

2. **函数** (Function)
   ```gdscript
   func _ready():
       print("游戏开始")
   
   func take_damage(amount):
       health -= amount
   ```

3. **条件判断** (If-Else)
   ```gdscript
   if health <= 0:
       die()
   ```

4. **循环** (Loop)
   ```gdscript
   for card in hand_cards:
       print(card.name)
   ```

5. **面向对象** (OOP)
   ```gdscript
   class_name Player
   var health = 100
   ```
