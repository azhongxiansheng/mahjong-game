# 第7周学习日志：网络多人游戏基础

## 学习目标

实现网络通信系统，支持多玩家在线游戏：
- WebSocket 通信
- 消息协议设计
- 客户端/服务器架构
- 游戏状态同步

## 核心概念讲解

### 1. 网络架构

**C/S 模型（客户端-服务器）：**
```
    Player 1 (Client)     Player 2 (Client)
         |                       |
         +-------+       +-------+
                 |       |
              GameServer
                 |       |
         +-------+       +-------+
         |                       |
    Player 3 (Client)     Player 4 (Client)
```

### 2. 通信流程

**玩家出牌消息流：**
```
玩家1: "我要出万1"
  ↓
客户端 → WebSocket → 服务器
  ↓
服务器验证并广播
  ↓
服务器 → WebSocket → 所有客户端
  ↓
其他玩家收到并更新UI
```

### 3. 消息格式

**JSON 格式的消息协议：**
```json
{
  "type": "discard_card",
  "player_id": 0,
  "card": { "suit": 0, "number": 1 },
  "timestamp": 1234567890
}
```

### 4. 房间和玩家管理

```
GameRoom
  ├── room_id: "room_001"
  ├── max_players: 4
  ├── current_players: 3
  ├── state: "playing"
  └── players: [Player1, Player2, Player3]
```

## 数据流示例

### 连接流程
```
1. Client 连接到 Server WebSocket
2. Client 发送 LOGIN 消息
3. Server 验证并返回 ROOM_STATE
4. Client 收到并显示房间信息
5. Server 广播新玩家加入消息
```

### 游戏流程
```
1. 所有玩家准备完成 → GAME_START
2. Server 分配初始手牌
3. 玩家轮流出牌 (PLAYER_ACTION)
4. Server 验证并广播 (GAME_STATE)
5. 胡牌时 (GAME_END)
```
