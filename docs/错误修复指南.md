# 🔧 错误修复指南 - GameUI 初始化问题

## ❌ 错误信息 (多个相关错误)

### 错误1: Invalid access to property 'card_pressed'
```
Invalid access to property or key 'card_pressed' on a base object of type 'Control'.
```

### 错误2: Invalid call to 'set_hand'
```
Invalid call. Nonexistent function 'set_hand' in base 'Control'.
```

### 错误3: Invalid assignment of property 'text'
```
Invalid assignment of property or key 'text' with value of type 'String' on a base object of type 'Nil'.
```

---

## 🔍 问题原因

这三个错误都源自同一个根本问题：**@onready 变量初始化失败**

**具体原因:**
1. ❌ GameUI 在主场景中被放在 `UILayer` 下，但代码查找路径为 `"GameUI"` 而非 `"UILayer/GameUI"`
2. ❌ @onready 变量在节点路径不存在时会被设置为 nil
3. ❌ 后续代码尝试访问 nil 对象的属性导致运行时错误

---


### 修复3: 安全的属性访问

**改进的 add_log_message():**
```gdscript
func add_log_message(message: String) -> void:
    """添加日志消息 - 安全版本"""
    if not game_log:
        print("⚠ game_log 未初始化，日志消息: %s" % message)
        return
    
    var timestamp = Time.get_ticks_msec() / 1000
    var formatted_msg = "[%.1f] %s" % [timestamp, message]
    game_log.text += formatted_msg + "\n"
    
    if game_log.get_line_count() > 0:
        game_log.scroll_to_line(game_log.get_line_count() - 1)
```
