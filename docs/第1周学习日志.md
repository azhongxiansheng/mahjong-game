## 📅 第1周学习计划

### 第1天（Day 1）：Godot 基础概念 - 节点树（1-2小时）

#### 📚 学习内容

1. **什么是节点（Node）？**
   - 节点是 Godot 中的基本单位
   - 每个节点都有类型（Node2D、CanvasLayer、Label 等）
   - 节点有属性（position、rotation、scale 等）

2. **什么是场景（Scene）？**
   - 场景是节点的树形结构
   - 一个 .tscn 文件就是一个场景
   - 场景可以包含子场景（嵌套）

3. **什么是场景树（Scene Tree）？**
   ```
   Main (根节点)
   ├── GameLayer
   ├── UILayer
   └── Player (子节点)
       ├── Sprite2D (Player 的子节点)
       └── CollisionShape2D
   ```

#### 🎯 实践任务

**任务1：创建一个简单的 Player 场景**

1. 在 Godot 中创建新场景
2. 根节点选择 `Node2D`，命名为 `Player`
3. 添加以下子节点：
   - `Sprite2D` (用来显示精灵)
   - `CollisionShape2D` (用来检测碰撞)
4. 保存为 `res://scenes/player.tscn`

**任务2：在主场景中添加 Player**

1. 打开 `res://scenes/main.tscn`
2. 在 Main 节点下添加一个 PackedScene 类型的节点
3. 选择加载 `player.tscn`
4. 这样 main 场景就包含了 player 场景

### 第3-4天（Day 3-4）：信号系统（Signal）（2-2.5小时）

#### 📚 学习内容

**什么是信号？**

信号是 Godot 中节点之间通信的方式。一个节点发送信号，另一个节点接收信号并做出反应。

```gdscript
# 定义信号
signal player_died

# 发送信号
func die():
    emit_signal("player_died")

# 在另一个脚本中接收信号
func _ready():
    player.connect("player_died", Callable(self, "_on_player_died"))

func _on_player_died():
    print("玩家死了！")
```

**为什么要用信号？**
- 解耦代码 (Player 不需要知道 GameManager 是否存在)
- 事件驱动编程
- 代码更容易维护

#### 🎯 实践任务

**任务1：为 Player 添加信号**

创建或编辑 `res://scripts/player.gd`：

```gdscript
extends Node2D

class_name Player

# 定义信号
signal health_changed
signal player_died

var health = 100
var max_health = 100

func _ready():
    print("Player 已加载")

func take_damage(amount: int):
    """受伤处理"""
    health -= amount
    emit_signal("health_changed", health)
    
    if health <= 0:
        die()

func die():
    """死亡处理"""
    print("玩家死亡！")
    emit_signal("player_died")
    queue_free()  # 删除这个节点
```

**任务3：创建 GameManager 来管理游戏**

创建 `res://scripts/game_manager.gd`：

```gdscript
extends Node

class_name GameManager

var player: Player
var enemies: Array[Enemy] = []

func _ready():
    # 获取 Player 节点
    player = get_tree().get_first_child_in_group("player")
    
    # 如果找不到，手动获取
    if not player:
        player = get_node("../GameLayer/Player")
    
    # 连接 player 的信号
    if player:
        player.connect("health_changed", Callable(self, "_on_player_health_changed"))
        player.connect("player_died", Callable(self, "_on_player_died"))
    
    # 连接所有敌人的信号
    for enemy in get_tree().get_nodes_in_group("enemies"):
        enemy.connect("enemy_died", Callable(self, "_on_enemy_died", [enemy]))

func _on_player_health_changed(health: int):
    """玩家血量改变时"""
    print("玩家血量: ", health)

func _on_player_died():
    """玩家死亡时"""
    print("游戏结束！玩家死亡")
    get_tree().reload_current_scene()

func _on_enemy_died(enemy: Enemy):
    """敌人死亡时"""
    print("敌人死亡！")
    enemies.erase(enemy)
    
    if enemies.is_empty():
        print("所有敌人已消灭，玩家胜利！")
```

**任务4：将脚本附加到场景**

1. 打开 `player.tscn`，选中 `Player` 节点
2. 在右侧检查器中，找到脚本部分，附加 `res://scripts/player.gd`
3. 对 `enemy.tscn` 和 `main.tscn` 做同样的操作

**任务5：给节点添加分组（Group）**

这样 GameManager 可以自动找到它们：

1. 选中 Player 节点，在右侧检查器找到**节点** → **分组**
2. 添加分组 `player`
3. 对每个 Enemy 节点添加分组 `enemies`

**任务2：手动触发信号**

在 main.gd 中添加按键控制来测试信号：

```gdscript
func _input(event: InputEvent) -> void:
    """处理用户输入"""
    if event is InputEventKey and event.pressed:
        if event.keycode == KEY_ESCAPE:
            print("按下 ESC，退出游戏")
            get_tree().quit()
        
        # 测试：按 P 键让 player 受伤
        elif event.keycode == KEY_P:
            if player:
                player.take_damage(10)
        
        # 测试：按 E 键让敌人受伤
        elif event.keycode == KEY_E:
            for enemy in enemies:
                enemy.take_damage(20)
```

运行游戏后：
- 按 **P** 看 Player 是否受伤
- 按 **E** 看 Enemy 是否受伤
- 检查输出窗口的日志
