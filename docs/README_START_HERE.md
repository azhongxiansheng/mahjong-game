## 🔍 故障排查

### 问题：听牌检查返回空列表
**可能原因**:
- 手牌不是13张 ← 检查输入
- 手牌无法组成胜手 ← 验证手牌配置
- 字牌被用于顺子 ← 仅用数字牌

**解决方案**: 查看 `听牌功能快速参考指南.md` 的"常见问题排查"部分

### 问题：胡牌检查返回false
**可能原因**:
- 手牌不是14张 ← 改为14张
- 手牌无法分解为1眼+4面子 ← 检查配置
- 眼牌重复或缺失 ← 确保恰好1个配对

### 问题：性能下降
**优化建议**:
- 实现缓存层
- 使用异步检查
- 预计算常见配置

**参考**: `听牌API使用示例.md` 的"性能优化"部分
