# 第5周学习日志：实现胡牌算法（麻将规则判断）

## 学习目标

理解麻将胡牌规则，实现完整的胡牌判断算法，包括：
- 牌型识别（顺子、刻子、对子、眼睛）
- 胡牌检测
- 番数计算

## 核心概念讲解

### 1. 麻将牌的基本组成

**标准麻将牌108张：**
- 万子（筒筒）：1-9，每种4张，共36张
- 筒子（筒筒）：1-9，每种4张，共36张
- 条子（竹子）：1-9，每种4张，共36张
- 字牌：东南西北中发白，每种4张，共28张

### 2. 基本牌型

```
顺子（顺）：三张连续的数字牌，如 万1万2万3
刻子（刻）：三张相同的牌，如 筒5筒5筒5
对子（对）：两张相同的牌，如 条9条9
眼睛（将）：胡牌必需的对子
```

### 3. 胡牌规则（标准麻将）

**基本胡牌条件：**
- 手中共13张牌（加上抽到的第14张）
- 包含1对眼睛（将）
- 剩余12张牌能组成4组牌
- 每组可以是顺子或刻子

**例子：**
```
胡牌示例：万1万1 万2万3万4 筒5筒5筒5 条6条7条8 字东字东
         眼睛    顺子1    刻子      顺子2   对子/眼睛
```

### 4. 番数计算（简化规则）

不同的牌型组合会得到不同的番数：
- 基本胡：1番
- 全顺：1番
- 全刻：1番
- 清一色：6番
- 龙：3番
