## 💡 技术亮点

### 1. 动态卡牌绘制
```gdscript
func _draw() -> void:
    # 绘制阴影、背景、边框
    draw_rect(rect, SHADOW_COLOR)        # 阴影
    draw_rect(rect, bg_color)            # 主体
    draw_rect(rect, BORDER_COLOR, false) # 边框
```

### 2. 智能文字颜色
```gdscript
var text_color = Color.WHITE if bg_color.get_luminance() < 0.5 else Color.BLACK
# 根据背景亮度自动选择文字颜色，确保对比度
```

### 3. 弹性动画
```gdscript
tween.set_ease(Tween.EASE_OUT)
tween.set_trans(Tween.TRANS_ELASTIC)
# 弹簧效果，让卡牌"弹出"而不是线性移动
```
