## 🔍 错误分析

### 错误信息

```
card_tile.gd:11 @ implicit_ready(): Node not found: "SuitLabel" 
(relative to "/root/Main/UILayer/GameUI/GameLayer/TableArea/PlayerHand/@Control@52").

card_tile.gd:11 @ implicit_ready(): Node not found: "SuitLabel" 
(relative to "/root/Main/UILayer/GameUI/GameLayer/TableArea/PlayerHand/@Control@52").

[重复 22 次，涉及 Label 和 SuitLabel]
```

### 根本原因

**问题**: `@onready` 修饰符在 `_ready()` 执行**前**自动执行，但我们的标签节点是在 `_ready()` **中**动态创建的。

```gdscript
// ❌ 问题代码
@onready var card_label = $Label        // 这行在 _ready() 前执行
@onready var suit_label = $SuitLabel    // 这行在 _ready() 前执行

func _ready() -> void:
    # 但节点是在这里创建的
    if not has_node("Label"):
        card_label = Label.new()        // 太晚了！@onready 已经失败
```

**错误原因**:
- Godot 中 `@onready` 是隐式的 `_ready()` 包装器
- 它在真正的 `_ready()` 之前执行
- 如果找不到节点，就会抛出错误
- 由于有 13 张卡牌，所以错误重复 13 × 2 = 26 次左右（但显示 22 个）

## ✅ 修复方案

### 修复前的代码

```gdscript
class_name CardTile
extends Control

# UI引用
@onready var card_label = $Label        # ❌ 会导致错误
@onready var suit_label = $SuitLabel    # ❌ 会导致错误

func _ready() -> void:
    # ... 其他代码 ...
    
    # ✓ 如果标签不存在，动态创建它们
    if not has_node("Label"):
        card_label = Label.new()
        card_label.name = "Label"
        add_child(card_label)
```

### 修复后的代码

```gdscript
class_name CardTile
extends Control

# UI引用 (不使用 @onready，改为在 _ready() 中初始化)
var card_label: Label = null    # ✓ 普通变量声明
var suit_label: Label = null    # ✓ 普通变量声明

func _ready() -> void:
    # ... 其他代码 ...
    
    # ✓ 如果标签不存在，动态创建它们
    if not has_node("Label"):
        card_label = Label.new()
        card_label.name = "Label"
        add_child(card_label)
```

### 修复要点

1. **移除 @onready**: 改为普通的变量声明
2. **类型提示**: 添加类型提示 `Label` 保持代码清晰
3. **初始化为 null**: 这样在 `_ready()` 前不会尝试查找节点
4. **在 _ready() 中初始化**: 在真正的 `_ready()` 中显式赋值

## 💡 最佳实践经验

### 何时使用 @onready

✅ **使用 @onready 的情况**:
```gdscript
# 节点在场景中预创建
@onready var label = $Label        # ✅ 节点在场景 (.tscn) 中存在

# 节点在父 _ready() 前已创建
@onready var child = $ChildNode    # ✅ 父级 add_child 在自己 _ready 前
```

❌ **不要使用 @onready 的情况**:
```gdscript
# 节点是动态创建的
@onready var label = $Label        # ❌ 错误，label 还不存在

# 节点可能不存在
@onready var optional = $Optional  # ❌ 错误，可能为 null
```

### 修复模式

**模式 1: 预创建节点（推荐）**
```gdscript
# 在 .tscn 场景中创建 Label 节点，然后用 @onready
@onready var label = $Label        # ✅ 推荐
```

**模式 2: 动态创建节点**
```gdscript
var label: Label = null            # ✓ 声明变量

func _ready() -> void:
    label = Label.new()            # ✓ 在 _ready() 中创建
    add_child(label)
```

**模式 3: 有条件的节点**
```gdscript
var label: Label = null            # ✓ 声明变量

func _ready() -> void:
    if has_node("Label"):
        label = $Label             # ✓ 可能存在
    else:
        label = Label.new()        # ✓ 否则创建
        add_child(label)
```
