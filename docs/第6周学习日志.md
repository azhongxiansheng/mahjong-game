## 核心概念讲解

### 1. 听牌（Tingpai）

**定义：** 缺一张牌就能胡的状态

**示例：**
```
手牌：万1万1 万2万3万4 筒5筒5筒5 条6条7条8 条9
缺少：条9 → 听牌
如果抽到条9 → 胡牌
```

### 2. 听牌的种类

```
单听：只有1张牌能听（如上例）
双听：有2张不同的牌能听
多听：有多张牌能听
```

### 3. 基础AI策略

**简单AI玩家需要：**
- 自动抽卡
- 自动打牌（出牌策略）
- 检测听牌
- 有概率胡牌

**AI 出牌策略（从简到复杂）：**
1. **随机出牌** - 最简单，随机选择手中的一张牌
2. **弃老打新** - 优先出1和9，保留中间牌
3. **危险度感知** - 避免出可能帮助对手胡的牌

### 4. 性能优化

听牌检测需要对每张可能的牌进行检测，这很耗时。优化方法：
- 缓存结果
- 只在需要时更新
- 并行计算
