## 📞 发布后支持

### 如果发现问题

1. **评估严重程度**
   - Critical (游戏无法运行): 立即修复
   - High (功能不可用): 在24小时内修复
   - Medium (功能有问题): 在一周内修复
   - Low (提示信息问题): 下个版本修复

2. **创建hotfix分支**
   ```bash
   git checkout -b hotfix/v1.0.1
   # 修复问题
   git commit -m "fix: description"
   git checkout main
   git merge hotfix/v1.0.1
   ```

3. **更新版本**
   - 更新 VERSION 文件
   - 更新 CHANGELOG.md
   - 创建新的git tag
