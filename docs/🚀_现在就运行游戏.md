## 🔧 如果遇到问题

### 问题 1：还是黑屏？
```
解决方案：
1. 检查 screen_base.gd 第 18 行是否为 visible = true
2. 在 Godot 编辑器重新保存场景 (Ctrl+S)
3. 按 F5 重新运行
```

### 问题 2：卡牌显示混乱？
```
解决方案：
1. 检查 hand_display.gd 的 add_card_display() 方法
2. 确保使用动态间距计算（有 spacing = 的那行）
3. 重启游戏
```

### 问题 3：文字太小看不清？
```
解决方案：
1. 编辑 game_ui.tscn
2. 查找 theme_override_font_sizes
3. 增大数字 (例如 28 → 32)
4. 保存并重启
```
