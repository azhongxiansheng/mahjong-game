## 📖 学习内容

### 1. GameUI 架构设计

#### GameUI场景结构
```
GameUI (Control)
├── GameLayer (Control)
│   ├── TableArea (Control) - 游戏桌面
│   │   ├── OpponentHand (GridContainer) - 对手手牌显示
│   │   ├── GameCenter (Control) - 游戏中央显示
│   │   │   ├── DiscardPile (GridContainer) - 弃牌堆
│   │   │   └── GameInfo (Label) - 游戏信息
│   │   └── PlayerHand (GridContainer) - 玩家手牌
│   └── ActionPanel (Control) - 操作面板
│       ├── ActionButtons (HBoxContainer)
│       │   ├── HuButton (Button) - 胡牌按钮
│       │   ├── TingButton (Button) - 听牌按钮
│       │   ├── PengButton (Button) - 碰按钮
│       │   └── PassButton (Button) - 跳过按钮
│       └── TileSelector (ItemList) - 出牌选择器
└── InfoPanel (Control) - 信息面板
    ├── PlayerStats (VBoxContainer) - 玩家统计
    ├── GameLog (RichTextLabel) - 游戏日志
    └── QuitButton (Button) - 退出按钮
```

### 3. 游戏交互流程

#### 游戏流程图
```
游戏开始
  ↓
显示对手手牌(背面)
  ↓
显示玩家手牌(正面)
  ↓
等待玩家操作
  ├→ 选择出牌 → 执行出牌 → 动画播放
  ├→ 胡牌检查 → 显示胡牌结果
  ├→ 听牌检查 → 显示听牌信息
  └→ 碰/杠 → 执行特殊动作
  ↓
轮到对手
  ├→ 显示对手出牌
  ├→ 更新弃牌堆
  └→ 检查胡牌
  ↓
回到等待玩家操作
```

### 4. UI交互细节

#### 手牌选择逻辑
```
1. 玩家点击手牌
   ↓
2. 高亮显示该卡牌
   ↓
3. 显示出牌确认按钮
   ↓
4. 玩家确认 → 执行出牌
   或 取消 → 返回
```

#### 动画系统
```
- 卡牌移动动画 (Tween)
- 淡入淡出效果
- 缩放动画
- 旋转动画
```

## 🎨 设计指南

### 颜色方案
```
主色: #2C3E50 (深蓝灰)
强调色: #E74C3C (红色) - 胡牌
次强调: #27AE60 (绿色) - 成功操作
背景: #34495E (略浅蓝灰)
文字: #ECF0F1 (浅灰白)
```

### 字体大小
```
标题: 24-32px
按钮: 16-20px
信息: 12-16px
提示: 10-14px
```

### 布局规范
```
边距: 10-20px
间距: 5-10px
卡牌大小: 80x120px (缩放后)
按钮大小: 100x50px
```
