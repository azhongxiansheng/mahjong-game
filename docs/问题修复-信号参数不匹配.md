# 🔧 问题修复报告 - 信号参数不匹配

**日期**: 2025-10-28  
**问题ID**: BUG-002  
**严重级别**: 🔴 高  
**状态**: ✅ 已解决

---

## 📋 问题描述

### 错误信息
```
Error calling from signal 'card_selected' to callable: 
'Control(hand_display.gd)::_on_card_selected': 
Method expected 1 argument(s), but called with 2.
```

### 触发时机
当点击卡牌选择时发生，导致完整流程测试中断。

### 根本原因
信号连接时使用了 `.bind()` 添加额外参数，但回调函数的参数个数与信号发送的参数不匹配。

---

## 🔍 详细分析

### 问题代码

**hand_display.gd** (之前):
```gdscript
# ❌ 使用 bind() 添加额外参数
card_tile.card_pressed.connect(_on_card_pressed.bind(card_tile))
card_tile.card_selected.connect(_on_card_selected.bind(card_tile))

# CardTile 发送信号时：
card_pressed.emit(card_data)      # 1个参数
card_selected.emit(card_data)     # 1个参数

# 但回调函数收到了 2 个参数：
func _on_card_pressed(tile: CardTile) -> void:      # 期望1个参数
func _on_card_selected(tile: CardTile) -> void:     # 期望1个参数
```

### 参数流程分析

```
CardTile.select():
  ↓
  card_selected.emit(card_data)      # 发送：card_data
  ↓
  bind(card_tile) 添加：card_tile     # 再添加
  ↓
  _on_card_selected(???, ???)         # 收到2个参数，但函数只定义1个！❌
```

---

## ✅ 解决方案

### 实现方式
直接连接信号，不使用 `.bind()`，在回调函数中直接处理 `CardData` 参数。

### 代码修复

**hand_display.gd** (之后):
```gdscript
# ✅ 直接连接，无需 bind()
card_tile.card_pressed.connect(_on_card_pressed)
card_tile.card_selected.connect(_on_card_selected)

# ✅ 参数与信号发送的参数匹配
func _on_card_pressed(_card_data: CardData) -> void:
    """卡牌被点击"""
    # 从 card_data 找到对应的 tile
    for tile in card_tiles:
        if tile.card_data == _card_data:
            select_card(tile)
            break
    card_pressed.emit(_card_data)

func _on_card_selected(_card_data: CardData) -> void:
    """卡牌被选中信号"""
    card_selected.emit(_card_data)
```

### 工作流程验证

```
CardTile.select():
  ↓
  card_selected.emit(card_data)      # 发送：card_data (1个参数)
  ↓
  _on_card_selected(card_data)       # 收到：card_data (1个参数) ✅
  ↓
  找到对应的 tile 并处理
```

## 🎯 为什么这样修复？

### 信号连接最佳实践

**方案 1: 使用 bind() 添加参数** ❌ (不适用此场景)
```gdscript
signal.connect(callback.bind(extra_param))
# 用途：当需要添加原信号中没有的额外参数
```

**方案 2: 直接连接，回调接收原信号参数** ✅ (本修复使用)
```gdscript
signal.connect(callback)
# 用途：回调函数接收信号发送的原始参数
```

### 为什么不用 tile 而用 card_data？
1. **信号参数是 CardData**: CardTile 发送的就是 card_data
2. **解耦**: HandDisplay 不需要直接接收 CardTile 对象
3. **清晰**: 参数类型明确，便于理解和维护

## 🔗 GDScript 信号知识点

### 信号的三种连接方式

**方式1: 基本连接**
```gdscript
signal.connect(callback)
# callback 接收信号的所有参数
```

**方式2: 使用 bind() 添加参数**
```gdscript
signal.connect(callback.bind(extra))
# callback 收到：(signal_param, extra)
```

**方式3: 使用 unbind() 忽略参数**
```gdscript
signal.connect(callback.unbind(1))
# 忽略信号的最后 1 个参数
```
