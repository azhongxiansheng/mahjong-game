### ❌ Test Case 1.3: 清一色胡牌 - 初始失败 (已修复)

**初始手牌**:
```
万1 万2 万3  (顺1)
万4 万5 万6  (顺2)
万7 万8 万9  (顺3)
万1 万1 万1  (刻) - 重复！
万2 万2      (眼)
```

**问题**: 
- 万1 出现了 4 次 (顺里1个 + 刻里3个)
- 万2 出现了 3 次 (顺里1个 + 眼里2个)
- 这破坏了标准的 14 张手牌组成

**修复**:
```
万1 万2 万3  (顺1)
万4 万5 万6  (顺2)
万7 万8 万9  (顺3)
万1 万1 万1  (刻)
万9 万9      (眼) - 改为万9，避免重复
```

**预期结果**: 下次运行应该通过 ✓
