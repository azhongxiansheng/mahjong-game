## 🎨 图标规格标准

### 推荐配置

| 属性 | 数值 |
|------|------|
| **宽度** | 40px |
| **高度** | 40px |
| **格式** | SVG (矢量) 或 PNG (栅格) |
| **颜色** | 白色 (#FFFFFF) 或 官方绿 (#09B83E) |
| **背景** | 透明 (PNG 使用 Alpha 通道) |
| **分辨率** | 72 DPI (网络) 或 96 DPI (屏幕) |

### 微信官方色彩

```css

Hex：#09B83E

RGB：(7, 193, 96)
Hex：#07C160
```

## 🚀 集成步骤

### 步骤 1: 验证图标文件

```bash
# 确认文件存在
ls -la D:\MahjongGame\assets\wechat_icon.svg

# 文件信息
文件名：wechat_icon.svg
大小：~2KB
格式：XML/SVG
编码：UTF-8
```

### 步骤 2: Godot 场景配置

图标已在场景中配置：

```gdscript
# 文件：scenes/loading_screen.tscn

[ext_resource type="Texture2D" path="res://assets/wechat_icon.svg" id="2_wechat_icon"]

[node name="WeChatIcon" type="TextureRect" parent="LoginContainer/VBoxContainer/WeChatLoginButton"]
texture = ExtResource("2_wechat_icon")
anchor_left = 0.0
anchor_top = 0.5
anchor_right = 0.0
anchor_bottom = 0.5
offset_left = 30.0
offset_top = -20.0
offset_right = 70.0
offset_bottom = 20.0
stretch_mode = 5
mouse_filter = 2
```

### 步骤 3: 脚本集成

脚本已完成集成，无需修改：

```gdscript
# 文件：scripts/loading_screen.gd

@onready var wechat_button: Button = $LoginContainer/VBoxContainer/WeChatLoginButton

func _ready() -> void:
    if wechat_button:
        wechat_button.pressed.connect(_on_wechat_login_pressed)

func _on_wechat_login_pressed() -> void:
    print("🔐 微信登录按钮被点击")
    await _request_wechat_login()
```

## 🆘 故障排查

### 问题：图标不显示

**症状**：微信登录按钮中没有图标  
**检查**：
1. 确认文件存在：`assets/wechat_icon.svg`
2. 检查 Godot 导入配置
3. 查看控制台错误信息

**解决方案**：
```gdscript
# 在 loading_screen.gd 中添加调试
var texture = load("res://assets/wechat_icon.svg")
if not texture:
    push_error("❌ 图标加载失败")
else:
    print("✅ 图标成功加载，尺寸:", texture.get_width(), "x", texture.get_height())
```

### 问题：图标变形/拉伸

**症状**：图标不是正方形，显示变形  
**原因**：拉伸模式设置错误  
**解决**：
```gdscript
# scenes/loading_screen.tscn 中检查
stretch_mode = 5  # STRETCH_KEEP_ASPECT (保持宽高比)
```

### 问题：图标模糊

**症状**：图标显示不清晰，像素化  
**原因**：使用了低分辨率PNG  
**解决**：使用 SVG 格式或更高分辨率的图片
