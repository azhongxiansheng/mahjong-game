## 已知未解（Phase 2 接手）

### 假设 L：aggro / fast pack 需要"被动防御"skill

baseline 1-6 累积 12 个假设中 11 个 address。剩余 **L** 是 game design 层面：

- aggro / fast pack 主题（增番 / 速胡）让所有 skill 在玩家 win 时 fire
- 4 家 ability 对称下，玩家 win rate 上限 ~25%；进攻 skill 收益不足以抵 HP 损失
- control 强是因为 soul_drain 在**对手 win** 时 fire（被动收益机制）

**结构性补救方向**（Phase 2 game design）：
- 给 aggro/fast pack 加 1-2 张被动防御 skill（如 iron_wall）
- 或重设计 spec §7.2 主题分布
- 或新增"事件节点"让玩家用 gold 买强 skill 弥补 pack 弱点
