## 🚀 快速使用指南

### 💾 立即部署（3 步）

#### 步骤 1️⃣：查看官方图标
访问以下任一官方渠道获取官方正版微信图标：

**微信开放平台**（推荐）
```
https://open.weixin.qq.com/
→ 登录
→ 文档 > 资源下载
→ 微信登录开发指南
→ 下载 UI 资源包
```

**GitHub 官方仓库**（备选）
```
https://github.com/wechat-sdk/wechat-ui-resources
→ Code → Download ZIP
→ 解压找 icon/ 目录
```

#### 步骤 2️⃣：替换项目文件
```bash
# 方案 A：使用现有 SVG 图标
# 项目已包含官方风格的图标
# 文件位置：assets/wechat_icon.svg

# 方案 B：替换为官方 PNG 图标
# 1. 下载官方 PNG 图标（40x40px）
# 2. 重命名为 wechat_icon.png
# 3. 放到 assets/ 目录
# 4. 更新 loading_screen.tscn：
#    path="res://assets/wechat_icon.png"
```

#### 步骤 3️⃣：测试验证
```bash
# 打开 Godot 编辑器
cd D:\MahjongGame\godot

# 打开 scenes/loading_screen.tscn
# 按 F5 运行场景
# 验证微信登录按钮中显示图标
```
