## 🔍 代码分析

### check_can_hear 方法详解

```gdscript
static func check_can_hear(hand: CardHand) -> Array:
	"""
	检查哪些牌能听牌（缺一张牌就能胡）
	返回：能听的牌列表
	"""
	var winnable_cards: Array = []

	# 尝试所有可能的牌 (万1-万9, 筒1-筒9, 条1-条9, 字1-字7)
	for suit in range(4):
		var max_num = 9 if suit < 3 else 7  # 字牌只有7种
		for number in range(1, max_num + 1):
			var test_card = CardData.new(suit, number)

			# 创建临时手牌进行测试
			var test_hand = CardHand.new()
			for card in hand.cards:
				test_hand.add_card(card)

			# 测试能否胡这张牌
			var result = check_win(test_hand, test_card)
			if result.can_win:
				winnable_cards.append(test_card)

	return winnable_cards
```

**工作原理**:
1. ✅ 遍历所有可能的牌 (1-31张牌)
2. ✅ 对每张牌，尝试添加到手牌中
3. ✅ 使用 `check_win()` 检查是否能胡牌
4. ✅ 收集所有能听的牌
5. ✅ 返回听牌列表

**性能**: O(N × M) 其中 N=34种牌, M=检查胡牌的复杂度

## 📋 测试用例详细分析

### Test Case 2.1: 基础听牌 (听1种牌)

**目的**: 验证系统能识别缺一张牌就能胡的简单情况

**手牌组成**:
```
万1  万2  万3     → 顺子 1 (完整)
万4  万4  万4     → 刻   1 (完整)
筒5  筒5  筒5     → 刻   2 (完整)
条6  条6  条6     → 刻   3 (完整)
字1               → 缺眼 (需要字1)

总计: 13张牌
缺少: 1张牌形成眼对
```

**期望结果**:
- ✅ `check_can_hear()` 应返回至少包含 `字1` 的列表
- ✅ 听数应该 = 1 (只能听字1)
- ✅ 添加字1后能胡牌

**验证逻辑**:
```
手牌13张 + 添加字1 = 14张
4个面子 (3顺1刻) + 1对眼 = 完整胡型
```

**期望结果**:
- ✅ `check_can_hear()` 应返回空列表 `[]`
- ✅ 听数应该 = 0
- ✅ 无论添加什么牌都无法胡

**理由**: 无法补全万1万2到顺子或刻，距离 > 1张
