### 2. 游戏流程管理 (GameFlow)

#### 游戏流程图
```
游戏初始化
    ↓
发初始手牌
    ↓
[游戏轮次循环]
  ├→ 第N轮开始
  │   ├→ 玩家1回合
  │   ├→ 玩家2回合
  │   ├→ 玩家3回合
  │   └→ 玩家4回合
  │       ↓
  │     检查胡牌
  │       ├→ 是 → 游戏结束
  │       └→ 否 → 下一轮
  └→ 循环16轮或直到有人胡牌
    ↓
游戏结束
```

#### GameFlow 核心方法

```gdscript
# 初始化
init_game(player_count: int)          # 初始化游戏

# 回合管理
start_round()                          # 开始新轮
start_turn()                           # 开始玩家回合
end_turn()                             # 结束玩家回合
end_game()                             # 结束游戏

# 逻辑检查
check_win(hand: CardHand) -> bool     # 胡牌检查
check_ting(hand: CardHand) -> bool    # 听牌检查

# 游戏控制
pause_game()                           # 暂停游戏
resume_game()                          # 恢复游戏
get_game_status() -> Dictionary        # 获取游戏状态
```

### 3. 逻辑集成

#### WinChecker 集成
```gdscript
func check_win(hand: CardHand) -> bool:
    var result = WinChecker.check_win(hand)
    
    if result.can_win:
        print("✓ 胡牌!")
        game_ui.show_win_result(result)
        game_ended.emit(current_player_index)
        return true
    
    return false
```

#### TingChecker 集成
```gdscript
func check_ting(hand: CardHand) -> bool:
    var result = TingChecker.check_ting(hand)
    
    if result.can_ting:
        print("✓ 可以听牌，听 %d 种牌" % result.ting_count)
        game_ui.add_log_message("可以听牌")
        return true
    
    return false
```

### 第2步: 创建GameFlow游戏流程控制

#### 目标: 实现完整的游戏流程管理

**关键方法:**
```
init_game()      → 初始化游戏
start_round()    → 开始轮次
start_turn()     → 开始回合
end_turn()       → 结束回合
end_game()       → 结束游戏
```

**信号系统:**
```
game_initialized    # 游戏已初始化
round_started       # 轮次开始
turn_started        # 回合开始
turn_ended          # 回合结束
game_ended          # 游戏结束
```

### 第3步: 集成胡牌和听牌检测

#### 目标: 在GameFlow中集成WinChecker和TingChecker

**实现:**
```
1. 在check_win()中调用WinChecker
2. 在check_ting()中调用TingChecker
3. 显示检查结果到UI
4. 触发相应的游戏事件
```

### 第4步: 完善UI交互

#### 目标: 增强按钮功能和信息显示

**增强功能:**
```
1. 胡牌按钮 → 调用 check_win()
```
