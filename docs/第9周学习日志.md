# 第9周学习日志：前端UI界面开发

## 学习目标

本周将学习如何为麻将游戏创建现代化的用户界面：
1. **主菜单UI** - 游戏启动界面、按钮、菜单导航
2. **登录注册界面** - 用户认证UI、表单验证
3. **大厅界面** - 房间列表、创建房间、加入房间
4. **游戏界面** - 手牌显示、出牌按钮、胡牌提示
5. **统计界面** - 战绩展示、排行榜、个人资料

---

## UI系统架构

### 1. UI管理器 (UIManager.gd)

负责所有UI界面的切换和管理：
```gdscript
class_name UIManager

var current_screen: String = "main_menu"
var screens: Dictionary = {}  # screen_name -> UI Scene

func show_screen(screen_name: String) -> void
func hide_screen(screen_name: String) -> void
func transition_to(screen_name: String) -> void
```

### 2. 主菜单 (MainMenuUI.gd)

游戏的首个界面，包含：
- 游戏标题和Logo
- 开始游戏按钮
- 设置按钮
- 退出按钮
- 背景音乐和特效

### 3. 登录界面 (LoginUI.gd)

用户认证界面：
- 用户名输入框
- 密码输入框
- 登录按钮
- 注册按钮链接
- 错误提示信息

### 4. 房间大厅 (LobbyUI.gd)

房间管理界面：
- 房间列表（ScrollContainer）
- 房间创建表单
- 玩家列表
- 准备就绪按钮
- 聊天框

### 5. 游戏界面 (GameUI.gd)

核心游戏界面：
- 13张手牌显示
- 牌桌布局（4个玩家位置）
- 弃牌堆显示
- 出牌/胡牌按钮组
- 游戏信息面板

### 6. 统计界面 (StatsUI.gd)

玩家数据展示：
- 个人战绩统计
- 排行榜显示
- 最近游戏记录
- 成就展示

## 关键UI组件

### ScreenBase（所有UI界面的基类）

```gdscript
class_name ScreenBase
extends Control

func _ready() -> void:
	# 初始化界面
	pass

func show_screen() -> void:
	# 显示界面（播放动画）
	visible = true

func hide_screen() -> void:
	# 隐藏界面（播放动画）
	visible = false

func on_enter() -> void:
	# 界面显示时的回调
	pass

func on_exit() -> void:
	# 界面隐藏时的回调
	pass
```

### 按钮样式系统

**ButtonStyle.gd** - 统一的按钮样式管理
```gdscript
static func get_primary_button_style() -> StyleBox
static func get_secondary_button_style() -> StyleBox
static func get_danger_button_style() -> StyleBox
```

### 输入表单验证

**FormValidator.gd** - 表单数据验证
```gdscript
static func is_valid_username(username: String) -> bool
static func is_valid_password(password: String) -> bool
static func is_valid_email(email: String) -> bool
```

## UI设计原则

### 色彩方案
- **主色**: #2C3E50（深蓝灰）
- **强调色**: #E74C3C（红色）
- **成功色**: #27AE60（绿色）
- **背景**: #34495E（暗灰）

### 字体
- **标题**: 24px, Bold
- **正文**: 14px, Regular
- **按钮**: 16px, Medium

### 间距和对齐
- 边距：16px
- 内间距：8px
- 组件间距：12px

## 动画效果

### 界面过渡
- 淡入/淡出（0.3秒）
- 滑动进入（0.4秒）
- 缩放弹跳（0.5秒）

### 交互反馈
- 按钮按下：0.1秒缩放
- 按钮悬停：色彩渐变
- 成功提示：绿色闪烁
