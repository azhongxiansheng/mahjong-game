## 📋 功能概述

### 胡牌 (Win) 检测
- **目的**: 判断玩家手牌是否满足胡牌条件
- **触发**: 玩家按下"胡"按钮或自动检测
- **返回**: WinResult (包含胡牌类型、番数等)

### 听牌 (Ting) 检测
- **目的**: 判断玩家可以听哪些牌
- **触发**: 玩家按下"听"按钮
- **返回**: TingResult (包含可听牌列表、听数等)

## 🔍 现有代码分析

### GameFlow 中的实现

```gdscript
func check_win(hand: CardHand) -> bool:
    """检查是否能胡牌"""
    if not WinChecker:
        print("⚠ WinChecker不可用")
        return false
    
    var result = WinChecker.check_win(hand)
    
    if result.can_win:
        print("✓ 胡牌!")
        if game_ui:
            game_ui.show_win_result(result)
        game_ended.emit(current_player_index)
        return true
    
    return false

func check_ting(hand: CardHand) -> bool:
    """检查是否能听牌"""
    if not TingChecker:
        print("⚠ TingChecker不可用")
        return false
    
    var result = TingChecker.check_ting(hand)
    
    if result.can_ting:
        print("✓ 可以听牌，听%d种牌" % result.ting_count)
        if game_ui:
            game_ui.add_log_message("可以听牌，听 %d 种牌" % result.ting_count)
        return true
    
    return false
```

## 🎮 用户交互流程

### 胡牌流程

```
用户按"胡"按钮
    ↓
GameUI._on_hu_pressed() 调用
    ↓
GameFlow.check_win(current_hand)
    ↓
WinChecker.check_win() 返回 WinResult
    ↓
如果胡牌成功 → 显示结果，游戏结束
如果胡牌失败 → 显示提示信息
```

### 听牌流程

```
用户按"听"按钮
    ↓
GameUI._on_ting_pressed() 调用
    ↓
GameFlow.check_ting(current_hand)
    ↓
TingChecker.check_ting() 返回 TingResult
    ↓
显示听牌结果 (可听牌种类和数量)
```

## 🛠️ 快速启动指南

### 步骤 1: 理解胡牌规则

**标准胡牌组合**:
- 1个眼 (2张相同的牌) 
- 4个面子 (顺/刻/杠)

**顺**: 3张连续的牌 (如 万1 万2 万3)  
**刻**: 3张相同的牌 (如 万1 万1 万1)  
**杠**: 4张相同的牌 (如 万1 万1 万1 万1)

## 💡 常见问题

### Q: 为什么胡牌检测失败？
A: 检查以下几点：
1. 手牌数是否正确 (14张或13张)
2. 是否有完整的眼睛 (2张)
3. 是否有4个完整的面子
4. 手牌是否满足胡牌规则

### Q: 听牌结果与预期不符？
A: 验证：
1. 手牌组合是否正确
2. 是否还差1张就能胡牌
3. 可听的牌是否被正确识别

### Q: 按钮没有反应？
A: 检查：
1. 按钮是否被正确连接
2. 信号是否被正确发送
3. 是否有运行时错误
