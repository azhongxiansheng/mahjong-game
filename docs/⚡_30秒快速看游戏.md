# ⚡ 30 秒快速看到游戏界面

**如果您只有 30 秒，就做这 3 件事：**

---

## ✅ 3 步快速上手

### 1️⃣ 打开 Godot

```
下载并安装: Godot 4.5+
https://godotengine.org/download
```

### 2️⃣ 打开项目

```
在 Godot 中:
点击 "打开项目"
选择: D:\MahjongGame\godot\
点击 "打开"
```

### 3️⃣ 按 F5 运行

```
按 F5 键
或点击工具栏的播放按钮 ▶️
```

**完成！** 🎮 游戏窗口就会出现！

## ❓ 常见问题

### Q: 找不到 Godot？
**A**: 
1. 去 https://godotengine.org/download 下载
2. 安装版本 4.5+ 
3. 安装后重启电脑

### Q: 按 F5 没反应？
**A**:
1. 确保光标在 Godot 窗口内
2. 尝试菜单 → 运行 → 播放

### Q: 游戏窗口全黑？
**A**:
1. 等 3-5 秒让它加载
2. 按 F5 重新启动
