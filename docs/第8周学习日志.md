# 第8周学习日志：数据库和用户账户系统

## 学习目标

本周将学习如何为麻将游戏实现持久化数据存储：
1. **用户账户管理** - 注册、登录、个人信息
2. **游戏记录保存** - 战绩、统计数据、回放
3. **数据库设计** - SQLite/JSON数据存储
4. **数据加密** - 密码安全存储

---

## 核心概念

### 1. 用户账户系统

**用户类 (User.gd)**
```gdscript
class_name User

var user_id: String           # 唯一用户ID
var username: String          # 用户名
var password_hash: String     # 密码哈希值
var email: String             # 邮箱
var created_at: int           # 创建时间
var last_login: int           # 最后登录时间
var player_stats: Dictionary   # 玩家统计信息
```

**玩家统计 (PlayerStats.gd)**
```gdscript
class_name PlayerStats

var total_games: int          # 总游戏数
var wins: int                 # 胜利次数
var total_fan: int            # 总番数
var average_fan: float        # 平均番数
var win_rate: float           # 胜率
var ranking: int              # 排名
```

### 2. 游戏记录系统

**游戏记录 (GameRecord.gd)**
```gdscript
class_name GameRecord

var record_id: String         # 记录ID
var game_id: String           # 游戏ID
var player_id: String         # 玩家ID
var timestamp: int            # 游戏时间
var result: String            # 游戏结果 (win/lose/draw)
var fan: int                  # 番数
var points_change: int        # 积分变化
var opponent_ids: Array       # 对手ID列表
```

### 3. 数据库设计

**用户表 (users)**
| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | STRING PRIMARY KEY | 用户ID |
| username | STRING UNIQUE | 用户名 |
| password_hash | STRING | 密码哈希 |
| email | STRING | 邮箱 |
| created_at | INTEGER | 创建时间戳 |
| last_login | INTEGER | 最后登录时间 |
| is_active | BOOLEAN | 是否激活 |

**游戏记录表 (game_records)**
| 字段 | 类型 | 说明 |
|------|------|------|
| record_id | STRING PRIMARY KEY | 记录ID |
| user_id | STRING FOREIGN KEY | 用户ID |
| game_id | STRING | 游戏ID |
| result | STRING | 结果 |
| fan | INTEGER | 番数 |
| timestamp | INTEGER | 时间戳 |

**玩家统计表 (player_stats)**
| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | STRING PRIMARY KEY | 用户ID |
| total_games | INTEGER | 总游戏数 |
| wins | INTEGER | 胜利数 |
| total_fan | INTEGER | 总番数 |
| ranking | INTEGER | 排名 |

### 4. 密码安全

**密码哈希 (使用SHA256)**
```gdscript
var password_hash = password.sha256_text()
```

**盐值存储（实际生产环境推荐）**
```gdscript
var salt = generate_salt()  # 生成随机盐值
var password_hash = (password + salt).sha256_text()
```

## 关键算法

### 1. 排名计算

```gdscript
# 基于Elo评级系统
var K = 32  # 基础系数
var expected_score = 1 / (1 + pow(10, (opponent_rating - player_rating) / 400))
var new_rating = player_rating + K * (actual_score - expected_score)
```

### 2. 胜率计算

```gdscript
var win_rate = float(stats.wins) / float(stats.total_games) * 100
```

### 3. 平均番数计算

```gdscript
var average_fan = float(stats.total_fan) / float(stats.total_games)
```
