## 🟡 发现的新问题 (Priority 2)

### 问题 A: GameUI 节点路径查询失败

**严重性**: 🟡 中等  
**影响**: GameFlow 和 GameTester 无法找到 GameUI  
**现象**:
```
⚠ 无法找到GameUI  (GameFlow._ready() 中)
⚠ 无法找到GameUI  (GameTester._init() 中)
```

**根本原因**: 
```gdscript
// GameFlow.gd 第 28 行
game_ui = get_tree().root.get_node_or_null("Main/GameUI")
// ❌ 问题: 路径不对，应该是从 Main 节点开始查找
```

**正确路径**: 
```
Main (根节点)
└── UILayer (CanvasLayer)
    └── GameUI (Control)
```

**解决方案**:
```gdscript
// 方案 1: 直接查找 GameUI
game_ui = get_tree().root.find_child("GameUI", true, false)

// 方案 2: 正确的相对路径
var main = get_tree().root.get_node_or_null("Main")
if main:
    game_ui = main.get_node_or_null("UILayer/GameUI")

// 方案 3: 使用完整路径（最可靠）
game_ui = get_tree().root.get_node_or_null("/root/Main/UILayer/GameUI")
```

**修复代码** (game_flow.gd 第 24-34 行):
```gdscript
func _ready() -> void:
    print("========== GameFlow 初始化 ==========")

    # ✓ 使用完整路径查找 GameUI
    var main = get_tree().root.get_node_or_null("/root/Main")
    if main:
        game_ui = main.get_node_or_null("UILayer/GameUI")
    
    if not game_ui:
        # 如果失败，尝试通过 find_child
        game_ui = get_tree().root.find_child("GameUI", true, false)
    
    if not game_ui:
        print("⚠ 无法找到GameUI - 稍后尝试")
        return

    print("✓ GameFlow已初始化")
```

### 问题 B: CardTile 中的标签为 null

**严重性**: 🟡 中等  
**影响**: 卡牌文字无法显示  
**现象**:
```
[CardTile] update_display: label为null
```

重复 13 次（每张卡牌一次）

**根本原因**: `card_tile.tscn` 场景中缺少 Label 和 SuitLabel 子节点

**当前 CardTile 脚本期望**:
```gdscript
@onready var card_label = $Label        # ❌ 场景中不存在
@onready var suit_label = $SuitLabel    # ❌ 场景中不存在
```

**解决方案**:

#### 选项 1: 在场景中手动添加子节点（推荐）

1. 打开 `godot/scenes/card_tile.tscn`
2. 在根节点 (CardTile Control) 下添加:
   - Label 节点: 
     - 名称: "Label"
     - Layout Mode: 设置为 "Anchors"
     - Anchor Left: 0.5, Anchor Top: 0.5
     - 位置: (0, -10)
     - 大小: (80, 50)
     - Text: "1"
     - Alignment: 居中
   
   - Label 节点:
     - 名称: "SuitLabel"
     - Layout Mode: 设置为 "Anchors"
     - Anchor Left: 0.5, Anchor Top: 0.5
     - 位置: (0, 20)
     - 大小: (80, 50)
     - Text: "万"
     - Alignment: 居中

#### 选项 2: 在代码中动态创建（临时方案）

```gdscript
func _ready() -> void:
    # ... 现有代码 ...
    
    # ✓ 如果标签不存在，动态创建
    if not has_node("Label"):
        card_label = Label.new()
        card_label.name = "Label"
        add_child(card_label)
    else:
        card_label = $Label
    
    if not has_node("SuitLabel"):
        suit_label = Label.new()
        suit_label.name = "SuitLabel"
        add_child(suit_label)
    else:
        suit_label = $SuitLabel
```
