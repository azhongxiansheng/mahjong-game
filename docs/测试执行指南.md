### Test 3: 完整流程测试

**快捷键**: `C`  
**测试函数**: `test_complete_flow()`  
**优先级**: 🔴 高

#### 执行步骤

1. **启动游戏**
   ```
   完整启动并看到所有初始化日志
   ```

2. **触发测试**
   ```
   按下键盘 C 键
   ```

3. **依次观察以下步骤**（每个步骤间隔约1秒）

   **步骤1: 显示玩家手牌** (0-1s)
   - 屏幕底部显示13张卡牌
   - 每张卡牌显示花色和数字
   - 日志输出手牌信息

   **步骤2: 显示对手手牌** (1-2s)
   - 屏幕顶部显示13张背面卡牌
   - 背面卡牌符号清晰

   **步骤3: 卡牌选择** (2-3s)
   - 选中第一张卡牌
   - 日志输出选中信息

   **步骤4: 显示弃牌堆** (3-4s)
   - 屏幕右下角显示4x4网格

   **步骤5: 播放动画** (4-5s)
   - 卡牌呈现动画效果
   - 可能有缩放或其他视觉效果

4. **完成验证**
   ```
   日志输出 "========== 完整流程测试完成 =========="
   总耗时约5秒
   ```

| 检查项 | 预期结果 | 状态 |

| 时间控制 | 每步间隔约1秒 | ⏳ |

| 选择响应 | 卡牌可被选中 | ⏳ |
| 动画效果 | 动画流畅，无卡顿 | ⏳ |
| 无错误输出 | 日志中无错误信息 | ⏳ |

#### 可能的问题与排查

| 问题 | 表现 | 解决方案 |
|------|------|---------|
| 流程中断 | 某个步骤不显示 | 查看是否有错误日志，逐个检查各子测试 |
| 卡顿明显 | 动画不流畅 | 检查帧率是否正常，可能需要优化 |

## 📞 故障排查流程

### 如果测试失败

1. **查看日志输出**
   - 搜索 ERROR 或 WARN 关键字
   - 检查是否有赤色或黄色警告

2. **检查相关代码**
   - 根据日志定位到具体代码行
   - 确认逻辑是否正确

3. **验证初始化**
   - 确认所有必要的节点都已初始化
   - 检查引用是否为 null

4. **逐步调试**
   - 逐个运行测试，而不是完整流程
   - 使用 print() 添加调试输出
