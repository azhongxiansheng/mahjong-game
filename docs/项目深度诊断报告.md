## 🔴 二级诊断：发现的问题

### 问题 #1: 线路编码警告 (CRITICAL)

**严重性**: 🔴 **中等** - 影响版本控制

**描述**: Git 检测到文件行尾编码不一致
```
warning: in the working copy of 'godot/main.tscn', LF will be replaced by CRLF
warning: in the working copy of 'godot/scenes/card_tile.tscn', LF will be replaced by CRLF
warning: in the working copy of 'godot/scenes/game_ui.tscn', LF will be replaced by CRLF
warning: in the working copy of 'godot/scripts/card_tile.gd', LF will be replaced by CRLF
warning: in the working copy of 'godot/scripts/game_ui.gd', LF will be replaced by CRLF
warning: in the working copy of 'godot/scripts/hand_display.gd', LF will be replaced by CRLF
```

**根本原因**: Windows 系统使用 CRLF，而 Git 期望 LF

**影响范围**: 7 个文件已修改
- godot/main.tscn (9 +/- 2 行)
- godot/scenes/card_tile.tscn (17 +/- 3 行)
- godot/scenes/game_ui.tscn (8 +/- 4 行)
- godot/scripts/card_tile.gd (26 +/- 1 行)
- godot/scripts/game_ui.gd (10 +/- 5 行)
- godot/scripts/hand_display.gd (9 +/- 1 行)
- godot/scripts/object_pool.gd (10 +)

**解决方案**:
```bash
# 检查当前 .gitattributes 配置
git config --global core.autocrlf false

# 或在项目中添加 .gitattributes
# 内容: * text=auto
```

### 问题 #3: 对象池实现可能存在问题 (MEDIUM)

**严重性**: 🟡 **中等** - 性能相关

**位置**: `scripts/object_pool.gd`

**发现**:
```gdscript
# 对象池直接创建 Button、Label、PanelContainer
# 这些是 Godot 节点类，需要添加到场景树中才能正常工作
button_pool.append(Button.new())  # ❌ 可能问题
label_pool.append(Label.new())
panel_pool.append(PanelContainer.new())
```

**问题分析**:
- Godot 中创建的节点如果不添加到场景树，某些属性可能无法正常工作
- 对象池中的节点没有父节点，可能导致初始化问题
- 没有检查节点是否已进入场景树

**建议修复**:
```gdscript
func _initialize_pools() -> void:
    # 为对象池节点创建一个父节点（通常在 _init 中）
    var pool_parent = Node.new()
    add_child(pool_parent)
    
    for i in range(initial_button_count):
        var btn = Button.new()
        pool_parent.add_child(btn)  # ✓ 添加到场景树
        btn.visible = false
        button_pool.append(btn)
```

### 问题 #4: GameFlow 节点初始化方式不规范 (MEDIUM)

**严重性**: 🟡 **中等** - 可能导致运行时错误

**位置**: `scripts/main.gd` 第 40-42 行

**代码**:
```gdscript
func initialize_game_flow() -> void:
    """初始化游戏流程"""
    game_flow = GameFlow.new()
    add_child(game_flow)
    game_flow._ready()  # ❌ 问题：手动调用 _ready()
```

**问题**:
- `GameFlow.new()` 创建的对象会自动调用 `_ready()`
- 手动再次调用 `_ready()` 会导致重复初始化
- `_ready()` 中依赖于 `is_node_ready()` 状态，手动调用时状态可能不正确

**正确做法**:
```gdscript
func initialize_game_flow() -> void:
    """初始化游戏流程"""
    game_flow = GameFlow.new()
    add_child(game_flow)
    # 不需要手动调用 _ready()，add_child 会自动触发
```

### 问题 #5: 手牌显示中的逻辑错误 (MEDIUM)

**严重性**: 🟡 **中等** - 可能导致卡牌移除错误

**位置**: `scripts/hand_display.gd` 第 102-103 行

**代码**:
```gdscript
# 如果移除的是选中的卡牌
if selected_tile == card_tiles[i] if i < card_tiles.size() else null:
    selected_tile = null
```

**问题**:
- 这行代码在移除卡牌后再检查索引，此时 `card_tiles` 已经被修改
- 条件语句的三元运算符使用不当
- 应该在移除前保存选中卡牌的引用

**正确做法**:
```gdscript
# 保存被移除的卡牌
var removed_tile = card_tiles[i]

# 从数组中移除
card_tiles.remove_at(i)

# 如果移除的是选中的卡牌，清空选择
if selected_tile == removed_tile:
    selected_tile = null
```

### 问题 #6: CardTile 中的等待语句可能阻塞 (MEDIUM)

**严重性**: 🟡 **中等** - 可能导致异步问题

**位置**: `scripts/card_tile.gd` 第 43-44 行

**代码**:
```gdscript
async def set_card(card: CardData) -> void:  # ❌ 异步函数但没有 await 调用者
    if not is_node_ready():
        await ready  # ❌ 等待 ready 信号可能导致卡顿
        update_display()
```

**问题**:
- 如果在 `set_card()` 中 `await ready`，调用方需要正确处理异步
- 在手牌显示中可能导致卡牌显示延迟

**建议**:
```gdscript
func set_card(card: CardData) -> void:  # ✓ 保持同步
    card_data = card
    if is_node_ready():
        update_display()
    # else: 稍后在 _ready() 中调用
```

### 问题 #7: GameUI 的节点路径查询冗余 (LOW)

**严重性**: 🟢 **低** - 性能优化空间

**位置**: `scripts/game_ui.gd` 第 46-77 行

**代码**:
```gdscript
func _initialize_missing_nodes() -> void:
    """初始化任何失败的 @onready 节点"""
    if not _player_hand_display:
        _player_hand_display = get_node_or_null("GameLayer/TableArea/PlayerHand")
    
    # ... 重复进行 10 次 get_node_or_null 调用
```

**问题**:
- 每次 `get_node_or_null()` 都需要遍历节点树
- 即使在失败后重复调用，也会再次遍历
- 没有缓存机制

**优化**:
```gdscript
var _node_cache = {}

func _initialize_missing_nodes() -> void:
    if _node_cache.is_empty():
        _cache_all_nodes()

func _cache_all_nodes() -> void:
    _node_cache["player_hand"] = get_node_or_null("GameLayer/TableArea/PlayerHand")
    # ... 一次性缓存所有节点
```
