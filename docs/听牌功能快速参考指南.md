### 胡牌检查

```gdscript
ting_cards = WinChecker.check_can_hear(hand: CardHand) -> Array[CardData]

# 返回值: [CardData, CardData, ...] 能胡的牌列表
```

## 🎯 关键规则

### ✅ 胜利条件
- 必须14张牌
- 1个眼 (配对) + 4个面子
- 面子: 顺子或刻子

### ✅ 顺子规则
- **仅数字牌**: 万、筒、条
- **不包括**: 字牌 (风、箭)
- 格式: N, N+1, N+2 (e.g. 万1,万2,万3)

### ✅ 刻子规则
- **所有花色**: 万、筒、条、字
- 格式: 三张相同的牌

### ✅ 听牌规则
- 13张手牌可以"听"
- 听 = 有某张牌能完成胜利配置
- 一次可以听多张不同的牌

## 🔍 常见问题排查

### 问题: `check_can_hear` 返回空列表

**可能原因**:
1. ❌ 手牌不是13张 → 改为13张
2. ❌ 手牌配置无法组成任何胜利手 → 检查手牌设计
3. ❌ 字牌被误用于顺子 → 仅在数字牌中使用顺子

### 问题: `check_win` 返回 false

**可能原因**:
1. ❌ 手牌不是14张 → 改为14张
2. ❌ 手牌无法分解为 1眼+4面子 → 检查组合
3. ❌ 眼牌重复或缺失 → 确保恰好1个配对

### 问题: 性能慢

**优化建议**:
1. 🔧 缓存常见的手牌配置
2. 🔧 使用查表法代替递归
3. 🔧 预计算所有可能的面子
