## 💡 **如果遇到问题**

### 问题 1: 没有看到听牌测试输出

**原因**: 可能没有按正确的按键或测试没有被触发

**解决**:
1. 确保游戏已启动 (看到快捷键说明)
2. 确保按了 [5] 或 [T] 键
3. 查看 Output 面板的完整日志
4. 重新运行 [5] 测试

### 问题 2: 出现 "check_can_hear not defined"

**原因**: WinChecker 中没有 check_can_hear 方法

**解决**:
1. 打开 win_checker.gd
2. 检查第 72 行是否有 `func check_can_hear()`
3. 如果没有，查看快速修复

### 问题 3: 听数计算不对或为 0

**原因**: 手牌组成可能设计不当，或听牌逻辑有问题

**解决**:
1. 查看 win_checker.gd 的 check_can_hear 实现
2. 检查测试用例的手牌组成
3. 参考分析报告中的手牌详解

### 问题 4: 运行时异常

**原因**: CardHand 或 CardData 相关问题

**解决**:
1. 查看完整的错误堆栈
2. 检查 CardHand.gd 和 CardData.gd
3. 确保手牌操作正确
