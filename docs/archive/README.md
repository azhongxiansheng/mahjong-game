# 历史文档归档

本目录保存已经退出当前产品方向的历史资料，不是项目事实源。

## 默认规则

- 常规需求分析、实现、Review 和文档检索不得读取或引用本目录。
- 只有用户明确要求追溯历史、审计旧决策或核对迁移来源时才可查看。
- 当前事实以仓库代码、根目录 `AGENTS.md` / `CLAUDE.md` 和活跃 `docs/superpowers/` 文档为准。
- 历史内容保持冻结，不为适配当前代码而维护；其中路径、命令、状态和结论可能已经失效。

`.rgignore` 已将本目录从默认 ripgrep 检索中排除。需要执行获准的历史追溯时，必须显式使用 `rg --no-ignore` 并限定到具体归档子目录。

## 归档批次

- `pre-multiplayer-roguelike/`：当前“多人麻将与嘴强道具”产品方向之前的旧肉鸽、抽卡、Steam、旧联机方案、旧发布说明、微信登录说明和 Run 平衡记录。
