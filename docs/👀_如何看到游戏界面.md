## 🎮 三种方式看到游戏

### 方式 1: 在 Godot 编辑器中运行（推荐） ⭐⭐⭐⭐⭐

这是最简单的方式，您可以实时看到游戏和调试信息。

#### 步骤 1: 打开 Godot 编辑器

```
1. 启动 Godot Engine (版本 4.5+)
2. 点击 "打开项目"
3. 选择: D:\MahjongGame\godot\
4. 选择 project.godot 文件
5. 点击 "打开"
```

#### 步骤 2: 加载项目

等待项目加载完成。您将看到：
- 左侧: 文件系统浏览器
- 中央: 场景编辑器
- 右侧: 检查器面板

#### 步骤 3: 运行游戏

**按下 F5 键** (或点击顶部菜单的 Play 按钮)

```
快捷键: F5
或者: 菜单 → 运行 → 播放
或者: 点击工具栏上的播放按钮 ▶️
```

#### 步骤 4: 查看游戏界面

您将看到一个新的游戏窗口出现，显示：
- ✅ 游戏主界面
- ✅ 13 张手牌
- ✅ 卡牌显示
- ✅ 游戏控制按钮

#### 步骤 5: 使用快捷键测试功能

按下以下快捷键查看不同功能：

```
[1] - 显示手牌
[2] - 卡牌选择
[3] - 出牌
[4] - 动画效果
[5] - 完整测试
[D] - 弃牌堆
[O] - 对手手牌
[C] - 完整流程
[ESC] - 退出测试
```

**示例操作**:
```
1. 按 F5 启动游戏
2. 游戏窗口出现，显示 13 张手牌
3. 按 [1] 查看手牌显示
4. 按 [2] 测试卡牌选择
5. 按 [3] 测试出牌
6. 按 ESC 返回菜单
```

### 方式 2: 在浏览器中查看（需要导出）

如果您想在浏览器中游玩，需要先导出为 HTML5 版本。

#### 步骤 1: 导出项目

在 Godot 编辑器中：

```
菜单 → 文件 → 导出项目 → HTML5
```

#### 步骤 2: 选择导出路径

选择导出位置，例如：
```
D:\MahjongGame\export\html5\
```

#### 步骤 3: 导出

点击 "导出项目"，等待导出完成。

#### 步骤 4: 在浏览器中打开

导出完成后，打开文件浏览器：
```
D:\MahjongGame\export\html5\index.html
```

用浏览器打开这个文件即可看到游戏。

**注意**: 某些功能（如本地文件访问）在浏览器中可能受到限制。

---

### 方式 3: 编译为独立应用

这是最完整的方式，可以生成 Windows/Mac/Linux 应用。

#### 步骤 1: 配置导出模板

在 Godot 编辑器中：
```
菜单 → 编辑 → 项目设置 → 导出
```

#### 步骤 2: 选择目标平台

```
点击 "新增导出配置"
选择: Windows 桌面 (或其他平台)
```

#### 步骤 3: 配置设置

设置应用名称、图标等：
```
应用名称: MahjongGame
版本: 1.0
...
```

#### 步骤 4: 导出

```
菜单 → 文件 → 导出项目
选择导出类型（例如 Windows .exe）
选择导出路径
点击导出
```

#### 步骤 5: 运行应用

导出完成后，在导出目录找到 .exe 文件，直接运行即可。

## ⚠️ 常见问题

### Q: 按 F5 没有反应？
**A**: 
1. 确保光标在 Godot 编辑器窗口内
2. 点击菜单 → 运行 → 播放 替代方案
3. 检查是否有编译错误（底部错误提示）

### Q: 游戏窗口出现但是全黑？
**A**:
1. 等待几秒让游戏加载
2. 按 F5 重新启动
3. 查看控制台错误信息

### Q: 看不到卡牌？
**A**:
1. 按 [1] 刷新显示
2. 按 [5] 运行完整测试
3. 检查是否有资源加载错误

### Q: 快捷键没有反应？
**A**:
1. 确保游戏窗口是活跃窗口
2. 点击游戏窗口确保焦点
3. 尝试其他快捷键 [1]-[5]

## 📞 需要帮助？

### 如果您卡住了

1. **检查 Godot 版本**
   - 需要 4.5+ 版本
   - 查看 Godot 菜单 → 关于

2. **查看错误信息**
   - 底部面板是否有红色错误
   - 查看 "输出" 标签页

3. **重新启动 Godot**
   - 关闭编辑器
   - 重新打开项目

4. **查看日志**
   - 查看 `user://` 目录下的日志文件
   - 了解具体的错误信息
