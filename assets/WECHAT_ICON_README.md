# 微信官方图标部署指南

## 📋 概述

本项目使用官方微信图标作为微信登录按钮的图标。本文档说明如何获取、验证和部署官方正版微信图标。

## 🔗 官方图标下载地址

### 推荐方案：微信开放平台
**地址：** https://open.weixin.qq.com/

### 获取步骤：

1. 访问 [微信开放平台](https://open.weixin.qq.com/)
2. 登录开发者账号（或注册新账号）
3. 导航至：**文档 > 移动应用接入 > 快速开始**
4. 查找 **"移动应用微信登录开发指南"**
5. 下载UI资源包，其中包含官方图标

### 备选方案：GitHub官方仓库
**地址：** https://github.com/wechat-sdk/wechat-ui-resources

## 📐 图标规格

| 属性 | 规格 |
|------|------|
| **推荐尺寸** | 40x40 px / 64x64 px |
| **格式** | PNG (推荐) 或 SVG |
| **背景** | 透明 |
| **颜色** | 白色（#FFFFFF）用于深色背景 |
| **风格** | 官方标准微信绿 (#09B83E) |

## 🎨 微信官方颜色

- **微信绿**：`#09B83E` 或 RGB(9, 184, 62)
- **按钮背景色**（本项目）：RGB(7, 193, 96) → `#07C160`

## 📂 文件结构

```
assets/
├── wechat_icon.svg          # SVG 格式（矢量，推荐用于响应式）
├── wechat_icon.png          # PNG 格式 40x40px（可选备用）
├── wechat_icon_64.png       # PNG 格式 64x64px（可选备用）
└── WECHAT_ICON_README.md    # 本文档
```

## ✅ 合规性检查

在使用微信官方图标时，请确保：

- [x] 从官方来源下载图标
- [x] 遵守微信品牌使用规范
- [x] 正确显示微信商标权利声明
- [x] 不修改、拉伸或扭曲官方图标
- [x] 在用户界面中清晰显示登录选项

## 🔐 品牌使用条款

根据微信开放平台的规定：

1. **标识使用**：只能用于微信登录/支付等官方功能
2. **禁止行为**：
   - 不能作为应用本身的图标
   - 不能与其他品牌混淆
   - 不能用于非授权的商业目的
3. **显示要求**：
   - 图标周围需要保留安全距离
   - 不能压缩或扭曲图标

## 🚀 在项目中使用

### 1. 复制图标文件
将下载的微信图标放在项目的 `assets/` 目录：
```
assets/wechat_icon.svg
```

### 2. 在 Godot 中引用
在 `scenes/loading_screen.tscn` 中已配置：
```gdscript
[ext_resource type="Texture2D" path="res://assets/wechat_icon.svg" id="2_wechat_icon"]
```

### 3. 配置按钮
微信登录按钮配置：
- **尺寸**：400x64 px
- **背景色**：RGB(7, 193, 96) - 官方微信绿
- **文本颜色**：白色 (#FFFFFF)
- **图标位置**：按钮左侧，距离边缘 30px
