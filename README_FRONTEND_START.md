## 🚀 30秒快速开始

### 1️⃣ 打开Godot项目
```bash
# Windows用户双击打开，或：
cd D:\MahjongGame\godot
godot
```

### 2️⃣ 运行主场景
- Godot菜单 → File → Open Scene
- 选择 `res://main.tscn`
- 按右上角的▶️播放按钮

### 3️⃣ 开始游戏
```
按 D    - 摸牌
按 1-9  - 出牌
按 I    - 查看手牌
按 S    - 查看状态
按 ESC  - 退出
```

## 🎯 核心系统

### GameState - 游戏状态管理
- 追踪游戏状态 (玩家回合/AI回合/胡牌等)

- 初始化和管理游戏

- 调用胡牌检测算法
- 管理AI回合

### Main - 主游戏场景
- 初始化所有系统
- 处理玩家输入
- 显示游戏信息

## 💡 常见问题

### Q: 游戏没有开始
**A**: 确保运行的是 `main.tscn`，不是 `loading_screen.tscn`

### Q: 看不到手牌
**A**: 按 `I` 键查看手牌信息 (当前是文本显示，UI改进中)

### Q: 不知道自己在做什么
**A**: 按 `?` 或查看 Godot 的 Output 日志 - 会有详细提示

### Q: AI不出牌
**A**: AI出牌有1秒延迟，让子弹再飞一会...

### Q: 胡牌没有显示
**A**: 胡牌时控制台会打印，后续会添加UI显示
